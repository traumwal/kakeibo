# kakeibo

毎月の出費を見える化して、無駄遣いを減らすための家計簿 PWA です。
データはすべて端末のブラウザ内(localStorage)に保存され、サーバーには送信されません。

## できること

- **サブスク・固定費**: 毎月/毎年の支払いを登録すると、月額・年額の合計、次の請求日、1時間あたりのコストを表示します
- **見直し候補**: 長く使っていない、1時間あたりのコストが高い、などのサブスクを、解約したときの年間節約額と一緒に表示します
- **単発支出**: 外食などを記録できます。割り勘の計算もできます
- **友達との貸し借り**: 「友達が立て替え」「自分が立て替え」を記録すると、友達ごとに借りている額・貸している額を集計します。精算(返済)も記録できます
- **ダッシュボード**: 今月の合計と前月比、金額付きのカテゴリ別横棒グラフ(予算線つき)、月別推移(固定費＋単発の積み上げ)

## サブスクの利用時間について

ブラウザ(PWA)からは、スマホの他のアプリの利用時間を自動で取得できません。代わりに次の2つで記録します。

- **月の利用時間(手入力)**: iPhone は「設定 → スクリーンタイム」、Android は「設定 → Digital Wellbeing」で確認した時間を入力すると、1時間あたりのコストを計算します
- **「今日使った」ボタン**: 最後に使った日を記録します。設定した日数(既定は30日)使っていないと見直し候補に出ます

## 支出の計上ルール

- 支出として集計されるのは **自分の負担額** だけです(友達の分を立て替えても、自分の支出は増えません)
- 友達が立て替えてくれた場合も、自分の負担額はその日の支出として計上し、同じ額を「借り」として記録します。返済しても支出は二重に計上されません

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 集計ロジックのテスト
npm run build    # 本番ビルド (dist/)
```

`main` に push すると GitHub Actions が GitHub Pages にデプロイします(リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください)。

## バックアップ

設定画面から JSON で書き出し/読み込みができます。機種変更やブラウザのデータ削除に備えて、ときどき書き出してください。
