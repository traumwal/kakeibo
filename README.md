# kakeibo

毎月の出費を見える化して、無駄遣いを減らすための家計簿 PWA です。
データは端末のブラウザ内(localStorage)に保存されます。設定画面からログインすると、Supabase を使ったクラウド同期(複数端末での共有・バックアップ)も使えます。

## できること

- **サブスク・固定費**: 一覧はロゴ・名前・金額・次回請求日とオン/オフのスイッチだけのシンプル表示。オフにすると翌月から集計されません(過去の分は残ります)。左スワイプ(パソコンは右クリック)か詳細画面のボタンで削除できます
- **サブスクの分類**: サブスクにも「何に使っているか」の分類を付けられます(定期券は「交通」、動画・音楽は「趣味・娯楽」、ChatGPT などは「AI・ツール」、ほかに家賃・通信費など)。名前を入れると分類も自動で選ばれます。サブスク一覧は分類ごとに月額の小計つきで並び、ホームのカテゴリ別では、その分類の中に固定費として入ります(固定費と日々の支出を色で分けて表示)。分類を選んでいないものも名前から推測して振り分け(「JR 定期券」なら交通)、推測できないものだけ「サブスク・固定費」にまとまります
- **見直し候補**: 「ほぼ使わない」にしたもの、長く「使った」の記録がないものを、オフにしたときの年間節約額と一緒に表示します
- **日々の支出**: 外食などを記録できます。支払い方法(現金・クレジットカード)も選べて、記録タブの「支払い別」でカードごとの合計(サブスク込み)がわかります。カードの締め日・支払日を設定すると、引き落とし日ごとの額と、ホームに「次の引き落とし」も出ます。友達との立て替えも記録できます
- **月 / 年の切り替え**: ホームと記録タブは、月ごと・年ごとに切り替えて見られます
- **友達との貸し借り**: 「友達が立て替え」「自分が立て替え」を記録すると、友達ごとに借りている額・貸している額を集計します。精算(返済)も記録できます
- **分類のカスタマイズ**: よく使う分類は最初から用意してあり、設定画面で追加・名前の変更・並べ替え・削除ができます。名前を変えると過去の記録も一緒に変わり、削除した分類の記録は「その他」に移ります
- **ダッシュボード**: 合計と前月比(年は前年同期比)、毎月の目安(既定2万円)との比較、カテゴリ別横棒グラフ(予算線つき)、推移グラフ(目盛りは目安が基準)

## サブスクをどのくらい使っているか

ブラウザ(PWA)からは、スマホの他のアプリの利用時間を自動で取得できないため、手間の少ない2つの方法で記録します。

- **どのくらい使ってる?**: 「よく使う / たまに / ほぼ使わない」をタップで選ぶだけ。「ほぼ使わない」は見直し候補になります
- **「今日使った」ボタン**: 押した回数から、直近30日の利用回数と1回あたりのコストを出します。設定した日数(既定は30日)押していないと見直し候補に出ます

## ドルのサブスク

金額はドルのまま登録でき、円の額は自動で換算します。

- **レート**: 請求日の公表レート(欧州中央銀行・[Frankfurter](https://frankfurter.dev) から取得)に、カードの海外事務手数料(既定 1.6%、設定で変更)を足して円にし、円未満は切り捨てます。取得で送るのは「ドル→円」と日付だけです
- **過去の月は動かない**: 一度換算した請求日のレートは保存して変えません。まだレートが出ていない請求(今日・先の予定)だけ、今のレートで「見込み」になります
- **明細の額で上書き**: カードの明細が来たら、サブスクの詳細画面「請求ごとの円の額」に実際の額を入れると、その額で集計します(空にすると自動の換算に戻ります)。ホームにも、この2週間のドルの請求が「確認」として出ます

## サービスのロゴについて

Netflix・Spotify など主なサービスは、名前を入れるとロゴ用のドメインが自動で入ります(それ以外は URL を手入力、または名前の頭文字アイコンになります)。
ロゴは Google の favicon サービス(`www.google.com/s2/favicons`)から取得するため、**ドメイン名だけ**が Google に送られます。金額などのデータは送信されません。一度表示したロゴはキャッシュされ、オフラインでも表示されます。

## 支出の計上ルール

詳しいルールはアプリの設定画面「集計のしかた」にもまとめています。

- ホーム上部の「サブスク・固定費 / 日々の支出」は払い方での分け方、カテゴリ別は何に使ったかでの分け方です。定期券は前者では固定費、後者では「交通」に入ります(交通の予算にも含まれます)
- 定期券・家賃・通信費・光熱費・保険は、「使った」の記録がないだけでは見直し候補になりません
- 年払いのサブスクは、設定で「毎月に分ける(÷12)」か「請求した月にまとめる」を選べます
- 支出として集計されるのは **自分の負担額** だけです(友達の分を立て替えても、自分の支出は増えません)
- 友達が立て替えてくれた場合も、自分の負担額はその日の支出として計上し、同じ額を「借り」として記録します。返済しても支出は二重に計上されません

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 集計ロジックのテスト
npm run build    # 本番ビルド (dist/)
```

`main` に push すると GitHub Actions が GitHub Pages にデプロイします(リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください)。

## クラウド同期 (Supabase)

ログインしている間は、データがクラウドにも保存され、同じメールアドレスでログインした端末どうしで自動で同期されます。
オフラインでも今まで通り使え、つながったときにまとめて同期します。2台で別々に編集しても、項目ごとにマージされます(同じ項目を両方で編集した場合は、後から同期した端末の内容が残ります)。

Supabase の URL とキーを設定しないでビルドした場合は、今まで通り端末の中だけで動きます。

### セットアップ

1. [Supabase](https://supabase.com) でプロジェクトを作る
2. SQL Editor で [`supabase/schema.sql`](supabase/schema.sql) を実行する(本人のデータしか読み書きできない設定 = RLS つき)
3. Authentication → URL Configuration の Site URL / Redirect URLs に公開 URL(例: `https://<user>.github.io/kakeibo/`)と `http://localhost:5173/` を追加する(新規登録時の確認メールのリンク先になります)
4. Project Settings → API の **Project URL** と **anon public key** を設定する
   - ローカル: `.env.example` を `.env.local` にコピーして値を入れる
   - GitHub Pages: リポジトリの Settings → Secrets and variables → Actions に `VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY` を登録する

anon key はアプリに埋め込む前提の公開キーです。**service_role key は絶対に使わないでください。**

## バックアップ

クラウド同期とは別に、設定画面から JSON で書き出し/読み込みもできます。機種変更やブラウザのデータ削除に備えて、ときどき書き出してください。
