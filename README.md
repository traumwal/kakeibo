# kakeibo

毎月の出費を見える化して、無駄遣いを減らすための家計簿 PWA です。
データは端末のブラウザ内(localStorage)に保存されます。設定画面からログインすると、Supabase を使ったクラウド同期(複数端末での共有・バックアップ)も使えます。

## できること

- **サブスク・固定費**: 一覧はロゴ・名前・金額・次回請求日だけのシンプル表示。タップすると詳細画面(年額・1時間あたりのコスト・最終利用日・見直し理由)に切り替わります
- **見直し候補**: 長く使っていない、1時間あたりのコストが高い、などのサブスクを、解約したときの年間節約額と一緒に表示します
- **単発支出**: 外食などを記録できます。割り勘の計算もできます
- **友達との貸し借り**: 「友達が立て替え」「自分が立て替え」を記録すると、友達ごとに借りている額・貸している額を集計します。精算(返済)も記録できます
- **ダッシュボード**: 今月の合計と前月比、金額付きのカテゴリ別横棒グラフ(予算線つき)、月別推移(固定費＋単発の積み上げ)

## サブスクの利用時間について

ブラウザ(PWA)からは、スマホの他のアプリの利用時間を自動で取得できません。代わりに次の2つで記録します。

- **月の利用時間(手入力)**: iPhone は「設定 → スクリーンタイム」、Android は「設定 → Digital Wellbeing」で確認した時間を入力すると、1時間あたりのコストを計算します
- **「今日使った」ボタン**: 最後に使った日を記録します。設定した日数(既定は30日)使っていないと見直し候補に出ます

## サービスのロゴについて

Netflix・Spotify など主なサービスは、名前を入れるとロゴ用のドメインが自動で入ります(それ以外は URL を手入力、または名前の頭文字アイコンになります)。
ロゴは Google の favicon サービス(`www.google.com/s2/favicons`)から取得するため、**ドメイン名だけ**が Google に送られます。金額などのデータは送信されません。一度表示したロゴはキャッシュされ、オフラインでも表示されます。

## 支出の計上ルール

- 支出として集計されるのは **自分の負担額** だけです(友達の分を立て替えても、自分の支出は増えません)
- 友達が立て替えてくれた場合も、自分の負担額はその日の支出として計上し、同じ額を「借り」として記録します。返済しても支出は二重に計上されません

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 集計ロジックのテスト
npm run build    # 本番ビルド (dist/)
```

`main` に push すると GitHub Actions が GitHub Pages にデプロイします(リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください)。

## クラウド同期 (Supabase)

ログインしている間は、データがクラウドにも保存され、同じメールアドレスでログインした端末どうしで自動で同期されます。
オフラインでも今まで通り使え、つながったときにまとめて同期します。2台で別々に編集しても、項目ごとにマージされます(同じ項目を両方で編集した場合は、後から同期した端末の内容が残ります)。

Supabase の URL とキーを設定しないでビルドした場合は、今まで通り端末の中だけで動きます。

### セットアップ

1. [Supabase](https://supabase.com) でプロジェクトを作る
2. SQL Editor で [`supabase/schema.sql`](supabase/schema.sql) を実行する(本人のデータしか読み書きできない設定 = RLS つき)
3. Authentication → Emails → Templates の「Magic Link」の本文に `{{ .Token }}` を入れる(ログイン用の6桁コードがメールに載るようにするため。リンクだけでもログインできますが、ホーム画面に追加した PWA ではコードのほうが確実です)
4. Authentication → URL Configuration の Site URL / Redirect URLs に公開 URL(例: `https://<user>.github.io/kakeibo/`)と `http://localhost:5173/` を追加する
5. Project Settings → API の **Project URL** と **anon public key** を設定する
   - ローカル: `.env.example` を `.env.local` にコピーして値を入れる
   - GitHub Pages: リポジトリの Settings → Secrets and variables → Actions に `VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY` を登録する

anon key はアプリに埋め込む前提の公開キーです。**service_role key は絶対に使わないでください。**

## バックアップ

クラウド同期とは別に、設定画面から JSON で書き出し/読み込みもできます。機種変更やブラウザのデータ削除に備えて、ときどき書き出してください。
